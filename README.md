# pair-assignment
Welcome to our humble FASTA analysis tool! Just copy this repository into your computer and run main.py.
Using this tool, you can:
1. Visualise headers in the FASTA file.
2. Perform sequence check to find incorrect symbols or undefined nucleotides (N).
3. Get sequence length, GC content, amount of undefined nucleotides, and find the start codon.
4. Translate DNA sequence into mRNA.
5. Translate the sequence into proteins (beginning at the start codon, ending at the fist termination codon)
6. Generate primers for sequence amplification.
7. Identify restriction sites for enzyme of interest.
